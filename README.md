# 具身智能工程与面试知识库

这是一份面向长期学习和复盘的具身智能笔记，覆盖机器人如何获得数据、如何学习策略、如何部署成系统，以及如何在真实世界里安全、连续地执行动作。

内容同时服务于两类场景：

- 建立完整知识框架，知道一个方法解决什么问题、代价是什么、什么时候不该用。
- 准备算法、VLA、机器人控制、感知导航和工程部署面试，能够从概念讲到真机落地。

正文不使用代码、函数名、内部文件路径或只对某一家公司有意义的命名。读者不需要打开源码，也能理解技术原理、工程取舍和常见故障。

## 怎么读

每个主题尽量回答四个问题：

1. 最基础的做法是什么。
2. 改进方法增加了什么信息或约束。
3. 它为什么可能有效，又引入了什么新风险。
4. 在真机、数据规模、算力和安全条件下，什么时候值得采用。

建议第一次按顺序阅读，先理解数据如何进入模型，再理解训练目标，最后理解部署和实时控制。准备面试时可以直接进入工程现象题库，按“不动作、抖、偏、慢、冲突、版本错误”等问题反向查找。

## 难度标记

- **高频**：公开面经和系统讨论中反复出现的核心题。
- **进阶**：需要在核心概念之上做取舍或解释实验。
- **真机**：重点不是名词，而是能否定位传感器、时序、网络、队列、控制或数据问题。
- **前沿**：仍在演进，答案应区分论文结论、工程经验和开放问题。

## 核心术语速览

**具身智能**：智能体通过感知环境并采取动作，在真实或仿真环境中完成任务。

**VLA**：视觉、语言和动作模型。它不仅理解图像与文字，还直接输出机器人可执行的动作或动作序列。

**行为克隆**：让模型模仿示范者的动作，是最常见的机器人模仿学习方法。

**Action Chunk**：一次预测多步动作，减少频繁推理和逐步误差累积。

**Diffusion Policy**：把动作生成看作从噪声逐步去噪的过程，擅长表示多种合理动作。

**Flow Matching**：学习从噪声走向目标动作的连续速度场，通常能用较少采样步骤生成动作。

**世界模型**：学习环境状态如何随时间变化，使智能体能够预测、规划或在内部模拟后果。

**仿真到现实**：把仿真中学到的策略迁移到真实机器人，主要难点是物理、视觉、传感器和时延差异。

**TTC / 实时分块**：在动作执行期间并行准备下一段推理，并把已经执行的动作作为条件，减少重规划时的跳变。

**SLAM**：机器人一边估计自身位置，一边构建环境地图。

**VLN / ObjectNav**：根据语言指令导航，或寻找指定类别的物体并到达其附近。

## 维护原则

- 新方法必须说明适用问题、收益、代价和失败边界，不能只写“用了某技术”。
- 新的面经主题先去重，再合并到四册，不为同一答案建立多个近义标题。
- 论文结论必须标明研究对象；单次真机成功不能自动等同于稳健泛化。
- 面向公开仓库的内容不记录账号、密码、设备凭据或生产环境私密路径。
- 代码实现细节不作为正文核心；更新时优先补充直觉、对比表、排障路径和验证证据。
